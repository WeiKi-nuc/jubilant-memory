## 项目一：多格式日志文件分析与可视化工具

### 任务描述

开发一个 "多格式日志文件分析与可视化工具"。该程序需要读取不同格式的日志文件，提取关键指标（如错误类型、时间戳、请求 IP），统计分析后生成结构化的文本可视化报告（如 ASCII 表格、趋势图），无需生成图片或 GUI 界面。

### 功能需求

1. 支持解析 `.log`（纯文本日志）、`.jsonl`（JSON 行日志）两种格式的日志文件
2. 提取并统计日志中的错误级别（INFO/WARN/ERROR/CRITICAL）分布
3. 按小时维度统计指定时间范围内的日志条目数量
4. 识别并列出出现频率最高的前 10 个错误信息
5. 生成包含统计结果和 ASCII 可视化图表的汇总报告

### 强约束条件

| 约束类型 | 具体要求 |
|----------|----------|
| 文件夹路径 | 程序必须从 `./log_input/` 目录读取日志文件，分析结果必须输出到 `./log_analysis_output/` 目录，且输出目录不存在时需自动创建 |
| 特定文件格式 | 最终生成的分析报告必须同时输出为 `.txt`（纯文本）和 `.json`（结构化数据）两种格式，文件名固定为 `log_summary.txt` 和 `log_summary.json` |
| 不可修改特定文件 | `./log_input/` 目录下的 `system_base.log` 文件为系统核心日志，代码中仅允许读取，禁止任何修改、删除、重命名操作，且需在代码中添加文件只读校验逻辑 |

### 文件结构要求

为保证代码模块化和可维护性，必须将代码拆分为 **至少 5 个独立文件**：

| 文件 | 职责 |
|------|------|
| `main.py` | 程序入口，处理命令行参数并调用核心分析逻辑 |
| `log_reader.py` | 负责不同格式日志文件的读取和解析 |
| `data_analyzer.py` | 实现日志数据的统计、过滤和分析逻辑 |
| `report_generator.py` | 生成文本可视化报告和 JSON 结构化报告 |
| `path_manager.py` | 管理输入输出路径的校验、创建和拼接 |
| `utils.py` | 包含时间格式转换、字符串处理等通用工具函数 |

### 技术栈

- **语言**：Python 3.9+
- **限制**：仅使用 Python 标准库，禁止使用第三方库（如 pandas、matplotlib 等）
