# jubilant-memory

## Python小程序练习提示词

以下为整理的不同难度、不同类型的Python小程序提示词，全部采用Markdown格式，你可以直接复制使用，也可以根据需求调整：

### 基础入门级（适合编程新手）
#### 提示词1：简易计算器
```markdown
### 小程序需求：简易四则运算计算器
1. 功能要求：
   - 接收用户输入的两个数字和一个运算符（+、-、*、/）
   - 根据运算符完成对应的四则运算
   - 处理除数为0的异常情况
   - 输出清晰的计算结果，格式如："5 + 3 = 8"
2. 技术要求：
   - 使用input()获取用户输入
   - 用if/elif/else判断运算符类型
   - 加入异常处理（try-except）
```

#### 提示词2：猜数字游戏
```markdown
### 小程序需求：猜数字小游戏
1. 功能要求：
   - 程序随机生成1-100之间的整数作为答案
   - 用户循环输入数字进行猜测
   - 提示用户猜测的数字"偏大""偏小"或"正确"
   - 猜对后显示用户猜测的次数，并询问是否重新开始游戏
2. 技术要求：
   - 使用random模块生成随机数
   - 用while循环实现多次猜测
   - 加入条件判断反馈猜测结果
```

#### 提示词3：单词大小写转换工具
```markdown
### 小程序需求：单词大小写转换工具
1. 功能要求：
   - 接收用户输入的任意英文单词/句子
   - 提供3种转换选项：全部大写、全部小写、首字母大写
   - 输出转换后的结果，并询问是否继续转换
2. 技术要求：
   - 运用字符串内置方法（upper()/lower()/capitalize()）
   - 用菜单形式让用户选择转换类型
```

### 进阶实用级（适合有基础的学习者）
#### 提示词1：文件内容统计工具
```markdown
### 小程序需求：文本文件内容统计工具
1. 功能要求：
   - 接收用户输入的文件路径（如：test.txt）
   - 统计文件中的总行数、总字符数、单词数（以空格分隔）
   - 统计出现频率最高的前3个单词
   - 处理文件不存在的异常情况
2. 技术要求：
   - 使用open()读写文件
   - 用字典统计单词出现次数
   - 加入文件操作的异常处理
```

#### 提示词2：简易待办事项清单
```markdown
### 小程序需求：简易待办事项清单
1. 功能要求：
   - 提供菜单：添加待办、查看所有待办、删除指定待办、退出程序
   - 待办事项需记录序号、内容、添加时间
   - 程序运行期间数据保存在列表中即可
   - 操作后给出明确的成功/失败提示
2. 技术要求：
   - 使用列表存储待办事项（每个待办用字典表示）
   - 用datetime模块获取时间
   - 循环展示菜单直到用户退出
```

### 趣味创意级（适合练手+拓展思维）
#### 提示词1：ASCII艺术字符画生成器
```markdown
### 小程序需求：简易ASCII字符画生成器
1. 功能要求：
   - 接收用户输入的单个字符（如：*）和一个简单图形类型（正方形、三角形）
   - 根据用户指定的边长/高度，用该字符生成对应的ASCII图形
   - 示例：输入*和正方形，边长5，输出5x5的*正方形
2. 技术要求：
   - 用嵌套循环控制图形的行和列
   - 对输入的图形类型做合法性判断
```

#### 提示词2：随机祝福语生成器
```markdown
### 小程序需求：随机祝福语生成器
1. 功能要求：
   - 预设3类祝福语（节日、生日、日常鼓励）
   - 用户选择祝福语类型后，随机输出该类下的一条祝福语
   - 支持自定义添加新的祝福语到对应分类中
2. 技术要求：
   - 用字典分类存储祝福语列表
   - 用random模块随机选取内容
   - 实现祝福语的增删功能
```

3. 所有提示词均为Markdown格式，结构清晰，可直接用于编程练习、作业设计或自学任务规划。
